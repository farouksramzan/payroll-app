Connect your Gmail

One-time setup needed: this tool sends from your Gmail, so Google requires an app key.
  1. Go to console.cloud.google.com → create a project (any name).
  2. Search "Gmail API" → Enable.
  3. APIs & Services → OAuth consent screen → External → add yourself as a test user.
  4. Credentials → Create credentials → OAuth client ID → Web application → add redirect URI http://localhost:5599/oauth2callback.
  5. Click Download JSON in the dialog Google shows (it saves a file named like client_secret_….json to your Downloads).
  6. Then click this button and pick that file — that's it:

You'll be taken to Google's own permission page to approve sending and reading email on your behalf. This tool never sees your password.
